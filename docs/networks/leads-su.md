# LEADS.SU — что важно для проекта

Прочитано 22.11.2026: правила вебмастера (https://webmaster.leads.su/agreement, редакция от 30.04.2024) и согласие на обработку ПДн ООО «СТУДИЯ ЛИДС». Политику обработки ПДн (PDF) прочитать не удалось — сервер не ответил. Это пересказ, не юридическое заключение.

## Подходит ли нам
- Самозанятые с регистрацией в РФ допускаются. Источники трафика регистрируются до начала работы; в регистрации могут отказать без объяснения причин.
- **Требования к своему сайту:** не меньше 100 уникальных посетителей в сутки за последний месяц, **платный хостинг**, смысловое содержание, без разделов «в разработке», без накрутки.
  - GitHub Pages — бесплатный хостинг → для регистрации сайта как источника нужен домен и платный хостинг.
  - Индексация выключена, трафика нет, все продукты в черновиках → сейчас сайт под требования не проходит.

## Что не сказано в правилах — спросить у support@leads.su письменно
1. Кто регистрирует креатив в ОРД и выдаёт ERID для финансовых офферов; какой рекламодатель указывается. (Без ERID наш шлюз оффер не опубликует.)
2. Postback: формат, параметры, статусы, sub-параметр для нашего `click_id`, IP-адреса отправки.
3. Можно ли показывать в карточке свои тексты об условиях (ставка, ПСК, плюсы и минусы, требования), а не только материалы оффера — правила запрещают менять материалы без разрешения оффера.
4. Холд, минимальная сумма выплаты, сроки, чеки самозанятого, работа с самозанятыми по банковским офферам.
5. Брендовый трафик и контекст по бренду банка — в правилах прямо не описаны, зависят от оффера.
6. Есть ли API (статистика, офферы) с официальной документацией.

## Правила, которые учитываем в работе
- Нельзя: накрутка, боты, самостоятельное выполнение целей, мотивированный трафик, спам, неодобренные источники. В проекте: `/go` не считает роботов, проверка партнёрских ссылок по умолчанию выключена (`CHECK_TRACKING=0`) — не включать для этой сети без разрешения.
- При подозрении на фрод выплаты блокируются, доказывать отсутствие нарушения должен вебмастер; убытки могут списать с баланса. Расчёт — по статистике платформы.
- Аккаунт блокируется без возможности восстановления после 90 дней без входов и переходов; при игнорировании запросов по источникам и без ответа 72 часа.
- Уведомления приходят в кабинет и на e-mail — проверять не реже раза в неделю.
- Условия меняются в одностороннем порядке без предупреждения.

## Согласие на ПДн LEADS.SU
Касается только регистрации вебмастера (ФИО, e-mail, телефон, Telegram, технические данные). Обязанностей вебмастера перед посетителями своего сайта не содержит. Наш сайт форм не имеет и персональные данные посетителей в сеть не передаёт.
