## Релиз 1 — текущее состояние
- Формы и сбор персональных данных: **нет**.
- Хранилище браузера: `localStorage.city` — выбранный город.
- Сторонние запросы из браузера: нет (`geoLookup: false` с 22.11.2026). При включении `geoLookup: true` — ipapi.co, запасной ipwho.is (получают IP-адрес посетителя). Сервисы за пределами РФ: нужна правовая оценка (IP-адрес может считаться персональными данными; трансграничная передача). Отключается в `data/site.json` (`geoLookup: false`).
- Шрифты и скрипты — с собственного сайта (без Google Fonts и CDN).
- Сравнение предложений: выбор хранится только в памяти страницы, состав — в адресе после `#` (на сервер не уходит). Новых записей в браузере нет.
- Переход по кнопке `/go/{id}`: в адрес добавляются страница-источник и utm-метки, если они были; бэкенд не хранит IP и user-agent.
- Аналитика: Яндекс Метрика подготовлена, но выключена (`metrikaId: null`). При включении — баннер согласия; без «Разрешить» счётчик не загружается; выбор хранится в `localStorage.consent`. Цель `bank_click` (клик по кнопке перехода) — для CTR. Яндекс Метрика — только после настройки приватности, без ПДн и без записи полей форм.
