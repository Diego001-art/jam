# 0004. Бэкенд для партнёрских ссылок и статистики

Статус: принято владельцем (вариант «статика + маленький бэкенд»). Хостинг и домен — не выбраны.

## Контекст
Сайт — статика на GitHub Pages. Для заработка на партнёрских программах нужны: замена ссылки без пересборки, учёт кликов, приём postback, статистика выплат. Статика этого не умеет. Репозиторий публичный: ссылки, суммы вознаграждения и условия выплат там хранить нельзя.

## Решение
Разделение данных:
| Где | Что |
|---|---|
| Репозиторий (`data/offers.json`) | публичное: id оффера, продукт, статус, рекламодатель, ERID, раскрытие |
| База бэкенда | сети, программы, партнёрская ссылка, вознаграждение, условия выплаты, клики, конверсии, выплаты |

Бэкенд (папка `backend/`, шаг 2 плана):
- `GET /go/{offerId}` — проверяет статус в базе, пишет клик, отвечает 302 на партнёрскую ссылку с click-id. Оффер отключён или не найден — 302 на официальную страницу продукта (`url`), без тупиков.
- `POST/GET /postback/{network}` — приём подтверждений; включается только для сетей с официальной документацией.
- Приём postback универсальный: у каждой сети свой маппинг полей и секрет в базе, по умолчанию выключен. Подключение — `backend/NETWORKS.md`.
- Админка (`/admin`, `backend/admin/index.html`) и JSON-API: сети, программы, офферы (смена ссылки действует сразу, пересборка не нужна), статистика кликов, конверсий и выплат. Вход по паролю (scrypt-хэш в `ADMIN_PASSWORD_HASH`), сессия в HttpOnly SameSite=Strict cookie, защита от CSRF заголовком, блокировка после 10 неудач. Запуск локально: `npm run backend`. На GitHub Pages бэкенд работать не может — нужен VPS или облако в РФ.
- Клик хранит: id оффера, страницу-источник, utm, время, click-id. **Не хранит IP, user-agent целиком и иные ПДн.**
- Запускается на VPS или в облаке в РФ (выбор не сделан); код без привязки к провайдеру (Node + SQLite/Postgres).

Проверка ссылок (`npm run backend:check`, запускать по cron на сервере): страница банка проверяется всегда, партнёрская ссылка — только с `CHECK_TRACKING=1` (запрос к трекеру может засчитаться сетью как клик). Также отмечаются активные офферы отключённой сети и офферы без переходов 14 дней. Уведомления: Telegram-бот (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`) и/или webhook; последние сбои видны в админке.

## Миграционный риск
Схему `products.json` не меняем. Добавлен `data/offers.json` (пустой), схема `Offer`, расширен `operator.type` (+ «самозанятый»). Админка контента не затронута. Поле `affiliateUrl` оставлено, но устарело.

## Открыто
- Показы кнопок и CTR не считаются, пока нет счётчика просмотров (Яндекс Метрика).
- Домен (нужен отдельный адрес для `/go/`, например `go.<домен>`); пока на github.io редирект не развернуть.
- Хостинг бэкенда.
- Юрист: маркировка рекламы и ERID для самозанятого; можно ли описывать ссылки как «рекламу» в конкретной схеме.
