# ADR 0003. Админка

Статус: принято.

Админка — одна статическая страница `/admin/`. Вход по паролю: личный ключ GitHub (fine-grained, только репозиторий `jam`, Contents: Read and write; Actions: Read — для статуса сборки) хранится в `public/admin/vault.json`, зашифрованный AES-GCM ключом из пароля (PBKDF2-SHA256, 600 000 итераций). Изменения — коммит JSON-файлов в `main`; сборку и публикацию делает GitHub Actions. Перед публикацией админка проверяет те же правила шлюза, что и валидатор сборки.
