# ADR 0001. Хостинг

Статус: принято на этап подготовки.

Сейчас сайт выкладывается на GitHub Pages (`/jam/`) через GitHub Actions: это бесплатно, админка коммитит изменения в репозиторий, сборка автоматическая. Ограничения: нет серверных 301 (старые адреса — статические страницы с canonical и meta refresh), robots.txt поисковики читают только в корне хоста, хостинг за пределами РФ.

Перед запуском с формами и индексацией — перенос на инфраструктуру в РФ с собственным доменом (ТЗ, разделы 7 и 9), серверные 301, robots.txt и sitemap в корне.
